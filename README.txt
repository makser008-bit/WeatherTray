Weather Tray - версія 0.4.2
===========================
English version: README_EN.txt


ПРО ПРОГРАМУ
------------
Weather Tray - невелика програма для Windows 11, яка показує поточну погоду прямо на панелі завдань,
поряд із системним треєм:

    [хмара 3°] ^

Місце визначається автоматично (геолокація), програма працює у фоні, запускається разом з Windows,
слідує темі Windows (темна/світла), мові системи та масштабу екрана. Віджет влаштований так само, як
у X11 Battery: це прозоре дочірнє вікно самої панелі завдань, тому воно ніколи не накладається на
повноекранні ігри чи інші вікна, а інтерфейс оформлений у стилі Windows 11.


ЩО ПОКАЗУЄ
----------
ВІДЖЕТ - іконка погоди (ясно, мінлива хмарність, хмари, туман, дощ, сніг, гроза; вдень і вночі)
і температура, наприклад "3°". Колір тексту залежить від теми Windows.

ПІДКАЗКА при наведенні (з'являється через ~0,4 с, малюється самою програмою: заокруглена, без білої
рамки, під тему - темна в темній темі, з тонкою сірою рамкою у світлій):
  * температура й опис погоди;
  * місто;
  * відчувається як ...;
  * вітер і вологість.


МЕНЮ (права кнопка миші по віджету; лівий клік нічого не робить)
-----------------------------------------------------------------
  * зверху - поточна погода й місто (сірим);
  * Оновити зараз;
  * Запускати разом з Windows (галочка);
  * Закріпити положення (галочка) - забороняє перетягувати віджет;
  * Скинути положення - повертає віджет до трея;
  * Монітор для віджета - якщо моніторів кілька; "Монітор 1 (основний)", "Монітор 2" ...;
  * Налаштувати погоду... - вікно налаштувань;
  * Мова / Language;
  * Версія, Вихід.


ПОЛОЖЕННЯ ВІДЖЕТА
-----------------
Віджет стоїть ліворуч від трея. Лівою кнопкою миші його можна перетягнути вздовж панелі завдань
(якщо положення не закріплене). Він не заїжджає на трей і годинник та не виходить за край панелі.
Відступ зберігається окремо для кожного монітора. Якщо на вашій панелі вже є інші віджети (наприклад
X11 Battery), просто пересуньте цей, щоб вони не накладалися.


НАЛАШТУВАННЯ
------------
  * Місцезнаходження: "Автоматично (геолокація)" або "Вручну". Вручну можна шукати міста, селища,
    райони міст або вписати координати (наприклад 47.91, 33.39). Пошук іде по OpenStreetMap.
  * Одиниці: °C або °F.
  * Оновлення: як часто оновлювати погоду, у хвилинах (5-180).
  * Тема: як у Windows (за замовчуванням), темна або світла.

Автоматична геолокація - за IP-адресою, тому вона наближена: з VPN чи в мобільній мережі місто може
бути іншим. Тоді оберіть місто вручну. Місто за замовчуванням ніде не зашите і зберігається лише
на вашому комп'ютері, коли ви самі обираєте його вручну.

Усі налаштування зберігаються в реєстрі (HKCU\Software\WeatherTray), окремих файлів немає.


МОВИ
----
Мова визначається автоматично за мовою Windows. Вбудовані: українська й англійська. Додати свою
можна файлом lang\xx.json (зразок - lang\_template.json): скопіюйте, перекладіть значення,
перезапустіть програму. Мова з'явиться в меню "Мова / Language".


ЗБІРКА
------
Запустіть build_exe.bat - з'явиться WeatherTray.exe. Потрібен лише Python 3 (бібліотеки не потрібні,
програма працює на чистому ctypes). Якщо щось не працює, подивіться weather_tray.log поруч з програмою.


ЗМІНИ
-----
0.4.0 - програму переписано на рушії віджета X11 Battery: дочірнє вікно панелі завдань, власне
        малювання (піксельна прозорість, шрифт Windows 11), власна підказка, меню Windows 11,
        налаштування в реєстрі, мови lang\xx.json. Раніше (0.1-0.3) використовувався Qt.
